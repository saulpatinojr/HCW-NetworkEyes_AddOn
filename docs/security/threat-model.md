# Threat model (lab edition)

| Asset | Threat | Control |
|---|---|---|
| Uploaded export (resource ids, subscription ids, address prefixes, NSG rules, tags, properties) | Disclosure to other visitors | UUID4 ids; 192-bit owner token (`secrets.token_urlsafe(24)`) returned once, stored as a SHA-256 hash, compared with `hmac.compare_digest`; 404 for unknown, foreign, expired or token-less requests (indistinguishable); in-memory only; 120-minute TTL sweep every 60 s; immediate `DELETE`; a restart purges everything |
| | Disclosure via logs | One guarded writer (`security/logging.py` -> `redaction.assert_no_visitor_data`) refuses any value that is not a count, duration, flag or allowed word; exception text passes `scrub()` (GUIDs, `/subscriptions/…` paths, secret-shaped strings); no uvicorn access log; ingestion warnings cite row numbers, column names and resource types only; `tests/security/test_logging_content_free.py` |
| | Disclosure via error bodies | `details` carries codes, counts, field names and a parse reason (line/column, column name), never cell content |
| | A VPN shared key in the export | The normalizer reads only whether `sharedKey` is present (`shared_key_set`), never its value; Resource Graph itself redacts it, and the sample uses a placeholder |
| Service | Resource exhaustion | 5 MB streamed limit (reading stops past it; `Content-Length` beyond it is refused before reading); 5,000 rows; 200 stored items with oldest-first eviction; per-client token bucket (10 uploads per 10 minutes, `Retry-After`); `asyncio.Semaphore(2)` with `503 overloaded` after 2 s; numeric settings bounded (`MAX_SETTING`); container 512m / 256 pids / one CPU, read-only root, `cap_drop ALL`, `no-new-privileges`, uid 10001 |
| | Bots | Human verification on `POST /api/assessments` with the `action` echo (`network-assessment-upload`) required and, when `NA_PUBLIC_HOST` is set, the token's `hostname` bound to it; **fail closed**: without `TURNSTILE_SECRET` uploads answer `503 turnstile_not_configured` unless `NA_ALLOW_NO_TURNSTILE=1`, which is for local development and e2e only and is logged as a warning at startup |
| | Client-address spoofing | Socket peer by default; the first `X-Forwarded-For` value only when `NA_TRUST_PROXY=1` (the lab host's reverse proxy sets it and nothing else can reach the loopback port); `CF-Connecting-IP` is never read |
| | CSV formula injection | Leading `= + - @ \t \r` neutralised on ingest (every non-JSON CSV cell); the bundle carries no CSV |
| | Path traversal | Static files resolve under the configured directory or 404; samples by fixed name; bundle files by exact key from a closed list; zip paths validated |
| | XSS | The pane writes every dynamic string through text nodes; CSP `default-src 'self'`, no inline script, `script-src`/`frame-src` admit the verification origin only when a site key is set; `base-uri 'none'`, `form-action 'self'`, `object-src 'none'` |
| | Clickjacking / framing by others | `frame-ancestors` from `NA_FRAME_ANCESTORS` (default `'none'`, plus `X-Frame-Options: DENY` then; the two site origins on the lab host, where Caddy enforces the same); top-level visits are redirected by the host |
| | Cross-origin misuse of the API | Exact-origin CORS from `NA_ALLOWED_ORIGINS` (empty in production: the pane is same-origin); preflight answers 204 only for a listed origin and 403 otherwise, never a wildcard |
| Azure estates | The lab reaching Azure | No cloud SDK installed (hash-pinned lock has none; Dependabot groups any attempt); `edition.py` refuses to start when `azure`/`msal`/`boto3` is importable or any of `IDENTITY_ENDPOINT`, `MSI_ENDPOINT`, `AZURE_CLIENT_SECRET`, `AZURE_FEDERATED_TOKEN_FILE`, `AZURE_CLIENT_ID`, `AZURE_TENANT_ID` is set, and installs a `sys.meta_path` finder that answers those imports with `ImportError`; `/api/health` reports `azureConnectivity: disabled-by-design`; `tests/security/test_edition_boundary.py` (manifests, lock, AST walk, endpoint and credential-symbol strings, fresh-process refusal, pane inputs, Dockerfile and compose); `publish-images.yml` proves `import azure` fails and a container with `IDENTITY_ENDPOINT` exits inside the built image |
| | **The container reaching the lab host's own identity** | The lab host is Arc-enabled, so a process on the host can reach the Arc agent's identity endpoint (`IDENTITY_ENDPOINT`, `/var/opt/azcmagent`). The container never can: it runs on the default bridge network (never `network_mode: host`), with no host mounts (no `/var/opt/azcmagent`, no socket), under the daemon's user-namespace remap, and `edition.py` refuses to start if the endpoint variables are ever injected. `docker-compose.yml` and the Dockerfile are asserted free of `network_mode` and `azcmagent` by the boundary test |
| Credentials | Phishing | No credential fields exist (the only input is the file picker); the notice says what is never asked; the boundary test asserts no password inputs |
| Rules | Tampering, drift | The registry is code in the image; `RULES_VERSION` and a digest of ids, versions, severities and `applies_to` are pinned in a test; `docs/rules/catalog.md` drift fails CI; version and count in `/api/health`; ported code changes only through `PROVENANCE.md` |
| Output | Misrepresented as an audit or as inference | Every finding carries an observed fact (hedge-free, enforced) and the field it came from; the rules the export cannot answer are listed with reasons; `NOT-FOR-PRODUCTION.md` in every bundle; compliance references marked for verification; "What this cannot tell you" panel |
| Site | Message spoofing to the pane page | The site accepts only `origin === the AddOn origin`, `source === frame.contentWindow`, `type/id/state` known; the pane posts only to `siteOrigins`, never `*` |
| Supply chain | Tampered dependencies or actions | `uv.lock` and `requirements.lock.txt` with hashes (`pip --require-hashes --no-deps`); base image by digest with a CI drift check; every action pinned by full SHA; Trivy before push; provenance, SBOM and attestation on every published image; `pip-audit` weekly |

Secrets: `TURNSTILE_SECRET` exists only in the lab host's Ansible vault (`vault_addon_network_assessment_turnstile_secret`);
public values (`NA_TURNSTILE_SITE_KEY`, `NA_PUBLIC_HOST`, origins, limits) in the role's env. Visitor data in the report
is returned only to the owner-token holder; it is the visitor's own data and is not redacted there, only in logs.

Out of scope for the lab edition (appliance concerns, upstream): Entra token validation, approvals, persistence, live
Resource Graph, metrics, diagnostic, BGP or cost reads, scope allow-lists. Out of scope by design: anything that would
need a credential.
